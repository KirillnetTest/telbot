# Telegram Vocabulary Bot

**Telegram Vocabulary Bot** -  это чат-бот для Telegram, предназначенный для изучения английской лексики с помощью интерактивных тестов. Бот позволяет пользователям практиковаться в переводе русских слов на английский, добавлять и удалять свои слова, а также отслеживать прогресс с использованием базы данных PostgreSQL.

### Настройка
Перед запуском основного модуля bot.py необходимо выполнить следующие шаги:
1. Создать Telegram-бот:
Откройте Telegram, найдите @BotFather и используйте команду /newbot для создания бота.
Скопируйте токен бота, предоставленный BotFather.
2. Создать базу данных PostgreSQL:
Настройте сервер базы данных PostgreSQL.
Выполните скрипт init_db.sql с помощью модуля init_db.py, чтобы создать необходимые таблицы и заполнить их начальными данными.
3. Установить необходимые библиотеки:
Установите требуемые пакеты Python, выполнив команду:
`pip install pyTelegramBotAPI psycopg2-binary python-dotenv`
4. Настроить переменные окружения:
Создайте файл .env в корневой папке проекта со следующими переменными:


| Имя переменной     | Описание значения переменной                      |
|---------------    -|---------------------------------------------------|
| TELEGRAM_BOT_TOKEN | Токен Telegram-бота, полученный от BotFather      |
| NAME_DB            | Имя базы данных PostgreSQL                        |
| USER_DB            | Имя пользователя для подключения к базе данных    |
| PASSWORD_DB        | Пароль пользователя для подключения к базе данных |
| HOST_DB            | Хост базы данных (например, localhost)            |
| POST_DB            | Порт для подключения к базе данных                |
|                    |                                                   |

### Команды бота

Бот поддерживает следующие команды и функции:

**“/start”** – Отображает приветственное сообщение с инструкциями.

**“/cards”** – Запускает тест с русским словом и четырьмя вариантами перевода на английский.

**“/cancel”** – Отменяет текущее действие и сбрасывает состояние бота.

**“Добавить слово ➕”** – Инициирует добавление новой пары слов (русский-английский) в словарь пользователя.

**"Удалить слово🔙"** - Инициирует удаление русского слова из словаря пользователя.

**"Дальше ⏭"** - Переходит к следующему вопросу теста.


Процесс тестирования:

Бот показывает случайное русское слово с четырьмя вариантами ответа (один правильный, три неправильных).

Пользователь выбирает вариант, получая обратную связь:

"✅ Correct! Great job!" при правильном ответе.

"❌ Неправильно! Попробуйте снова." при неправильном ответе.

Результаты сохраняются для отслеживания прогресса.

Управление словами:

Добавление слова: введите русское слово и его английский перевод.

Удаление слова: укажите русское слово для удаления.


### Модули
**bot.py** - Основной модуль для запуска бота.

Основные функции:

-`check_db_connection():` Проверяет подключение к базе данных и наличие таблиц.

-`get_random_word(user_id): `  Извлекает случайное слово из общего или пользовательского словаря.

-`get_random_english_words(user_id, exclude_word, limit)` : Получает случайные неправильные варианты ответа.

-`add_user_word(user_id, russian, english)`: Добавляет слово в словарь пользователя.

-`save_answer_result(user_id, russian_word, user_answer, correct_answer, is_correct)`: Сохраняет результаты теста.

-`generate_question_markup(user_id, russian_word, correct_answer)`: Создает клавиатуру с вариантами ответа.

Обработчики команд:

-`/start`: Отправляет приветственное сообщение.

-`/cards`: Запускает тест.

-`/cancel`: Отменяет текущие действия.


**init_db.py** - Утилита для инициализации базы данных PostgreSQL.

Основная функция:

`execute_sql_file(filename)` : Выполняет скрипт init_db.sql для настройки схемы базы данных.



**init_db.sql** - SQL-скрипт для создания схемы базы данных и заполнения начальными данными.

Создает таблицы: words, user_words, results.

Добавляет индексы для оптимизации производительности.

Вставляет 10 начальных пар слов (русский-английский).

### Использование

1. Запуск бота:

Выполните команду python bot.py.

Отправьте /start в Telegram, чтобы увидеть приветственное сообщение.

2. Прохождение теста:

Отправьте /cards, чтобы начать тест.

Выберите ответ из предложенных вариантов.

Используйте Дальше ⏭ для перехода к следующему вопросу.

3. Управление словами:

Нажмите Добавить слово ➕ для добавления новой пары слов.

Нажмите Удалить слово🔙 для удаления слова.

Используйте /cancel для отмены действия.

4. Обработка ошибок:

Ошибки базы данных отображаются как: "⚠️ Ошибка подключения к базе данных."

Некорректные вводы вызывают сообщения о повторной попытке.
